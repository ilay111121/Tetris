TETRIS FOR ANDROID

This is a Buildozer project for generating an Android APK.
An APK has NOT been built or tested here.

Build using GitHub:
1. Create a new GitHub repository.
2. Upload the contents of this folder, including .github/workflows/build-apk.yml.
3. Go to Actions -> Build Android APK -> Run workflow.
4. When complete, download the artifact tetris-android-apk.

Alternative on Linux with Buildozer installed:
buildozer android debug
The APK will appear in bin/ if the build succeeds.
